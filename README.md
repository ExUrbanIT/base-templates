# ExUrban Base Templates

This repository contains reusable HTML/CSS website templates developed by ExUrban Technologies.  
These templates serve as starting points for small business builds and internal client projects.

## Includes:
- Home page layouts
- About/Contact/Services pages
- Gallery and menu boards
- Standalone feature sections

## Usage:
Fork or clone this repo to rapidly prototype a new client site.  
Each folder is self-contained and production-ready.
